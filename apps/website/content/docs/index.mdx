## Play a track

Once your Player and source plugin are configured:

```ts
const { queue, track } = await player.play({ guildId, channelId }, 'https://your-media-host.example/song.mp3');

if (track) await queue.node.setVolume(70);
```

The URL is a placeholder. A source plugin must resolve it to playable audio. Follow the [getting-started tutorial](/docs/getting-started) for setup and a complete source example.

## Requirements

- Node.js 22.18+ and ESM.
- A Discord bot and a gateway library such as discord.js.
- A source plugin to recognize queries and provide audio.
- FFmpeg 9 shared libraries on the machine running embedded playback. [Install FFmpeg](/docs/installation/ffmpeg).

You can run the audio engine inside the bot or use a [remote Remedia node](/docs/remedia/remote).
