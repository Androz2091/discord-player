discord-player v8 manages Discord music queues and delegates audio playback and voice transport to [Remedia](https://github.com/twlite/remedia), a Rust engine. You own the Discord client and forward Gateway payloads; discord-player handles queues, source selection, history, events, and playback control.

## A recommended learning path

<Steps>
### Install the runtime

Choose [embedded or remote playback](/docs/installation) and verify FFmpeg 9 on the machine that actually runs audio.

### Connect a Discord client

Follow [Create a player](/docs/getting-started/create-player). The client supplies the bot user ID and forwards Gateway voice events.

### Add a source

[Write a direct-media source plugin](/docs/getting-started/source-plugin). Queries are not playable until a plugin resolves both track metadata and a media source.

### Start playback

[Play the first track](/docs/getting-started/play-track), then learn [queue controls](/docs/guides/queues) and [events](/docs/guides/events).

### Go further

Extend the [plugin host](/docs/plugins), run [remote Remedia](/docs/remedia/remote), or use the [migration guide](/docs/migration).

</Steps>

## What v8 owns

| discord-player                               | Remedia                                              |
| -------------------------------------------- | ---------------------------------------------------- |
| Source matching, metadata, stream resolution | Demux, decode, resample, filters                     |
| Per-guild queues, repeat, shuffle, history   | Playback timeline, pause, seek, volume               |
| Player and queue events                      | Native Discord voice transport and session lifecycle |
| Typed source plugins and legacy adapter      | Embedded or authenticated remote audio nodes         |

The same Remedia engine is used for embedded and remote playback. The plugin host currently runs with discord-player on the application side; remote plugin execution is not a v8 guarantee.

<Callout title="Requirements">
  Node.js 22.18 or newer, ESM, and an installed v8 package. Embedded hosts need FFmpeg 9 shared libraries; remote-only
  bot hosts do not. Read [installation](/docs/installation) before copying the runtime example.
</Callout>
