title: Getting started
description: Choose a Remedia runtime and prepare your discord-player v8 installation.
---

Discord Player v8 uses Remedia for audio processing. Start with Node.js 22.18.0 or newer and an ESM application.

Choose where audio processing runs:

- **Embedded:** Remedia runs in the bot's Node.js process. Install the native addon and compatible FFmpeg 7 shared libraries on that machine.
- **Remote:** the bot connects exclusively to `remedia-server`. Install FFmpeg on the server machine; the bot machine needs no local FFmpeg installation.
