Use **Node.js 22.18 or newer** and an **ESM** application. This branch uses Remedia `0.1.0-dev.3`. discord-player v8 depends on `@remedia/client`. Where audio runs determines whether the bot needs native FFmpeg libraries.

## Install discord-player

```bash
pnpm add discord-player
# If running an embedded node, also install the native addon:
pnpm add @remedia/node
```

For the [discord.js example](/docs/getting-started/create-player), also install `discord.js`. You may use any other Discord Gateway client instead.

### Embedded mode

```ts
nodes: [{ id: 'local', type: 'embedded' }];
```

The bot loads the native Remedia addon and FFmpeg shared libraries on its own host. Install [FFmpeg 9](/docs/installation/ffmpeg) **before** starting the bot. Native packages are selected by the package manager's optional dependencies.

### Remote mode

```ts
nodes: [
  {
    id: 'media-1',
    type: 'remote',
    url: 'wss://audio.example.com/v1/ws',
    auth: { username: 'bot', password: process.env.REMEDIA_PASSWORD! },
  },
];
```

The remote server owns FFmpeg, playback, and Discord voice packet delivery. Your bot still forwards Discord Gateway credentials to Remedia. Use a secure WebSocket connection and keep credentials out of source control.
