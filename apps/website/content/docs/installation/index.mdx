Discord Player v8 requires Node.js 22.18+ and ESM.

```bash
pnpm add discord-player
```

You'll also need a Discord gateway library such as discord.js. Discord Player doesn't manage the bot's gateway connection.

## Embedded playback

Run audio inside your bot process:

```bash
pnpm add @remedia/node
```

```ts
nodes: [{ id: 'local', type: 'embedded' }]
```

Install [FFmpeg 9 shared libraries](/docs/installation/ffmpeg) on the bot machine. Having an `ffmpeg` command alone doesn't guarantee the required libraries are available.

This is the simplest option for a first bot.

## Remote playback

Run Remedia on another machine:

```ts
nodes: [{
  id: 'media-1',
  type: 'remote',
  url: 'wss://audio.example.com/v1/ws',
  auth: { username: 'bot', password: process.env.REMEDIA_PASSWORD! },
}]
```

The audio server needs FFmpeg; the bot machine doesn't. Follow the [remote deployment guide](/docs/remedia/remote) for server setup and authentication.
