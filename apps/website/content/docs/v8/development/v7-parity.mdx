contracts. Matching method names alone is not evidence of parity. All listed test
names refer to deterministic suites under the packages' tests directories.

## Removed unpublished v8 experiments

`queueOptions`, nested `searchOptions`, public `pluginId`/`source` selectors,
constructor `sourceHosts`, public `player.sources`, `player.queues`, the plugin kind
discriminator and reserved runtime kind, source-prefixed generic plugin type names,
`playRaw`, `GuildQueuePlayerNodePlayResult`, the always-throwing Track
`getStreamableSource`, the unused derived-emitter wrapper, and standalone queue/voice/play stubs were removed.
`GuildNodeManager` and `GuildQueueHistory` are the actual manager class names.
`PlayerNodeInitializerOptions` retains the real v7 spelling.

The duplicate `source.resolve` HTTP endpoint was removed. High-level source.search
and normalized generic metadata.execute dispatch through the shared registry.
DSP-specific event declarations without runtime implementations were removed.

## Genuine architecture differences

- Remedia owns decoding, filters, transport and native session recovery. V7's decoded
  StreamInterceptor, demux/codec plumbing, mutable output bitrate and DSP-object APIs
  have no pretend replacements. Use native source descriptors and filtergraphs.
- URL/file resources do not expose bytes to client callbacks. onAfterCreateStream
  requires an encoded local Readable on an embedded node; descriptor hooks support
  remote operation sources. Guilds are never silently migrated to accommodate bytes.
- Generic metadata currently uses direct HTTP. Generic Remedia operation forwarding
  is future work in Remedia, outside this task. Native operation-source playback is
  preserved independently.
- Core Gateway events use normalized states rather than discord.js VoiceState or
  VoiceConnection objects. Channel occupancy requires an authoritative resolver;
  stage request-to-speak remains integration-owned.
- Synced lyrics retain the active line until the next timestamp rather than v7's
  closest-line/two-second heuristic. Mutable polling interval controls were removed.
  Native progress has no notification API, so timing includes bounded snapshot rechecks.
- willPlayTrack is observational; its old decoded StreamConfig/done latch is replaced by awaited resource hooks. willAutoPlay retains its real tracks/done selection contract.
- Raw native descriptors intentionally use native Remedia types; v7 stream-type and
  decoded audio resource options are not accepted as if they still worked.

Detached Track and Playlist models keep metadata, display helpers and persistence.
Use `player.play(channel, trackOrPlaylist)` instead of model-owned play shortcuts;
use an explicit queue for seek and resource lifetime. Shared standalone models do
not retain or infer a guild's live AudioResource or global queue ownership. For
persisted data use `deserialize()` with the versioned format; legacy input remains
covered by serialization tests. Manager lookups return null when absent.
