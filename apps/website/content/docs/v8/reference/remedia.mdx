---
title: Remedia configuration
description: Node options for embedded and remote playback.
---

Pass nodes to the Player with `nodes`. This is separate from `player.nodes`, the queue manager.

## Embedded node

```ts
nodes: [{ id: 'local', type: 'embedded', capacity: 8 }];
```

| Field      | Description                                     |
| ---------- | ----------------------------------------------- |
| `id`       | Unique node name                                |
| `type`     | `'embedded'`                                    |
| `capacity` | Maximum simultaneous guild sessions. Default 64 |

It uses `@remedia/node` in your process and needs the [FFmpeg 9 shared libraries](/docs/v8/installation/ffmpeg) on that machine.

## Remote node

```ts
nodes: [
  {
    id: 'audio-1',
    type: 'remote',
    url: 'remedias://audio.example.com',
    auth: { username: 'bot', password: process.env.REMEDIA_PASSWORD! },
  },
];
```

| Field      | Description                                                                      |
| ---------- | -------------------------------------------------------------------------------- |
| `id`       | Unique node name                                                                 |
| `type`     | `'remote'`                                                                       |
| `url`      | `remedia://`, `remedias://`, `ws://`, or `wss://`. The path defaults to `/v1/ws` |
| `auth`     | `{ username, password }` for HTTP Basic authentication. Do not log it            |
| `capacity` | Overrides the server's reported player maximum for selection                     |

The bot machine does not need FFmpeg when it only uses remote nodes. Use TLS and server-side access limits. See [remote playback](/docs/v8/remedia/remote).

## Client options

These Player options go to the Remedia client:

| Option               | Default | Description                         |
| -------------------- | ------- | ----------------------------------- |
| `requestTimeoutMs`   | 15000   | Timeout for ordinary requests       |
| `maxPendingRequests` | 128     | Concurrent requests per remote node |

Voice joins use a longer deadline. `connectTimeoutMs` on `queue.connect()` or `player.play()` sets the overall initial join deadline, and channel moves keep their own.

## Inspect nodes

```ts
await player.initialize(botUserId);

console.log(player.nodeSnapshots);
console.log(player.getRemedia().nodes);
```

## Placement

A guild stays on the node it was assigned to. A queue's `selectNode` option influences the first placement. See [node capacity and selection](/docs/v8/remedia/operations).

For session migration, event generations, and the protocol, see the [Remedia client reference](https://github.com/twlite/remedia/blob/main/apps/docs/content/docs/client/overview.mdx).
