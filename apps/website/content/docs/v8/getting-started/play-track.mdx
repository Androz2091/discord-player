---
title: 3. Play a track
description: Join a voice channel and start audio.
---

In your bot's play command, call `player.play()` with the guild ID, voice channel ID, and a direct audio file:

```ts
const result = await player.play(
  { guildId: interaction.guildId!, channelId: voiceChannel.id },
  'https://your-media-host.example/song.mp3',
);

if (result.track) {
  console.log('Playing', result.track.title);
} else {
  console.log('No matching audio file');
}
```

Use an actual URL for an MP3, Ogg, or WAV file. The example address is a placeholder. `voiceChannel` should be the user's voice channel, resolved using your Discord library. The [Player setup](/docs/getting-started/create-player) must be initialized before playback.

## Listen for events

Register these once during bot startup:

```ts
player.events.on('playerStart', (queue, track) => {
  console.log('Playing', track.title, 'in guild', queue.guildId);
});

player.events.on('playerError', (queue, error, track) => {
  console.error('Failed to play', track.title, error);
});

player.on('error', console.error);
```

`player.play()` creates or reuses a guild queue and connects to the selected voice channel. It does not register a Discord slash command. Your Discord library handles command registration and locating the user's channel.
