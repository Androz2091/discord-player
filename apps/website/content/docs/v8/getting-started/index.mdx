This tutorial uses discord.js to connect to Discord and an embedded Remedia node to play audio. Discord Player itself is not tied to discord.js.

## Before you start

You need Node.js 22.18+ with ESM, a Discord bot token, permission to join and speak in a voice channel, and [FFmpeg 9 shared libraries](/docs/installation/ffmpeg).

Install the packages:

```bash
pnpm add discord-player discord.js @remedia/node
```

We'll use a small source plugin that recognizes direct MP3, Ogg, and WAV URLs. You don't need to implement a full music provider to follow along.
