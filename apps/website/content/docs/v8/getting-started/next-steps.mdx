---
title: 4. Control playback
description: Pause, skip, seek, and inspect a queue.
---

Get the queue for a guild:

```ts
const queue = player.getQueue(guildId);
if (!queue) return;

console.log(queue.currentTrack?.title);
console.log(queue.size); // Tracks waiting to play

await queue.node.pause();
await queue.node.resume();
await queue.node.seek(30_000); // Milliseconds
await queue.node.setVolume(70); // Percent
await queue.skip();
```

`queue.stop()` stops the current track but keeps upcoming tracks. `queue.destroy()` removes the queue and closes its voice session.
