Discord Player v8 requires Node.js 22.18 or newer and ESM.

<Callout type="info" title="Starting a new bot?">
  `npm create music-bot@dev my-bot` creates a project with everything on this page already installed and configured. See
  [Getting started](/docs/v8/getting-started). Read on to add Discord Player to an existing project.
</Callout>

```bash
pnpm add discord-player@dev
```

v8 is a preview release, so install it with the `dev` tag. Without a tag, your package manager installs v7.

You also need a Discord gateway library such as discord.js. Discord Player does not open the gateway connection itself.

## Choose where audio runs

|                            | Embedded                               | Remote                                |
| -------------------------- | -------------------------------------- | ------------------------------------- |
| Audio engine               | Inside your bot process                | A separate `remedia-server`           |
| Extra package on the bot   | `@remedia/node`                        | None                                  |
| FFmpeg 9 libraries         | On the bot machine                     | On the server machine                 |
| Local streams from plugins | Supported                              | Not supported                         |
| Best for                   | First bots, single-machine deployments | Scaling, isolating audio from the bot |

### Embedded playback

```bash
pnpm add @remedia/node@0.1.0-dev.7
```

`@remedia/node` must be the exact version that your `discord-player` release depends on, and the `latest` tag is older. The generator and the [manual setup](/docs/v8/getting-started/manual-setup) use `0.1.0-dev.7`, which matches `discord-player@dev` at the time of writing. Your package manager reports a peer dependency warning when the versions differ.

```ts
import { Player } from 'discord-player';

const player = new Player({
  nodes: [{ id: 'local', type: 'embedded' }],
  send,
});
```

`nodes` can be omitted. A Player without `nodes` uses one embedded node named `local`.

Install the [FFmpeg 9 shared libraries](/docs/v8/installation/ffmpeg) on the bot machine. An `ffmpeg` executable alone is not enough.

### Remote playback

```ts
import { Player } from 'discord-player';

const player = new Player({
  nodes: [
    {
      id: 'audio-1',
      type: 'remote',
      url: 'wss://audio.example.com/v1/ws',
      auth: { username: 'bot', password: process.env.REMEDIA_PASSWORD! },
    },
  ],
  send,
});
```

`send` is the gateway callback from the [manual setup tutorial](/docs/v8/getting-started/create-player). The audio server needs FFmpeg and the bot does not. See [remote playback](/docs/v8/remedia/remote) for server setup.
