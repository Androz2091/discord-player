## Register a plugin

```ts
const player = new Player({
  nodes: [{ id: 'local', type: 'embedded' }],
  send: (guildId, packet) => sendGateway(guildId, packet),
  plugins: [mySourcePlugin()],
});
```

`mySourcePlugin` and `sendGateway` belong to your application. For a complete example, see [getting started](/docs/getting-started/source-plugin).

Most bots can register a source plugin and leave the underlying operation details alone.
