---
title: Source plugins
description: Add music providers by teaching Discord Player how to find tracks and open audio.
---

A source plugin tells Discord Player how to recognize a query, find tracks, and return audio that Remedia can play. Discord Player has no built-in providers, so you register the plugins your bot needs.

```ts
import { Player } from 'discord-player';

const player = new Player({
  plugins: [mySourcePlugin()],
  send,
});
```

`mySourcePlugin` is your plugin. The [getting-started tutorial](/docs/v8/getting-started/source-plugin) builds a working one.
