With a track playing, retrieve its queue:

```ts
const queue = player.getQueue(guildId);
if (!queue) return;

await queue.node.pause();
await queue.node.resume();
await queue.node.seek(30_000);
await queue.node.setVolume(65); // Percent, not linear 0–1 gain
```

A queue stores upcoming tracks separately from the current Track:

```ts
console.log(queue.currentTrack?.title);
console.log(queue.size); // Number of upcoming tracks
console.log(queue.node.playbackTime); // Elapsed media time in milliseconds
```

Use `await queue.skip()` for a managed skip and `await queue.stop()` to stop the current playback without deleting the upcoming queue. `await queue.destroy()` releases the session and clears state.
