---
title: 1. Create the player
description: Connect discord.js gateway events to Discord Player.
---

Create `src/player.ts`:

```ts title="src/player.ts"
import { Client, Events, GatewayIntentBits } from 'discord.js';
import { Player } from 'discord-player';
import { directMedia } from './direct-media.js';

export const client = new Client({
  intents: [GatewayIntentBits.Guilds, GatewayIntentBits.GuildVoiceStates],
});

export const player = new Player({
  nodes: [{ id: 'local', type: 'embedded' }],
  plugins: [directMedia()],
  send(guildId, packet) {
    const guild = client.guilds.cache.get(guildId);
    if (!guild) throw new Error('Cannot find the guild shard');
    return guild.shard.send(packet);
  },
});

client.on('raw', (packet) => player.receive(packet));
client.once(Events.ClientReady, async (ready) => {
  await player.initialize(ready.user.id);
  console.log('Discord Player ready');
});
```

`send` sends voice connection requests through discord.js. `receive` forwards incoming gateway events to Discord Player. Both are required.

The `directMedia` import comes from [step 2](/docs/getting-started/source-plugin). Create that file before running your bot, and use one Player instance throughout the application.

After registering your command handlers, connect the bot:

```ts
await client.login(process.env.DISCORD_TOKEN);
```

Keep the token in an environment variable, not in your source code.
