---
title: 2. Add a source
description: Play direct audio URLs with a small source plugin.
---

Discord Player needs a source plugin to turn a query into playable media. For now, we'll support direct MP3, Ogg, and WAV URLs.

Create `src/direct-media.ts`:

```ts title="src/direct-media.ts"
import { definePlugin, Track } from 'discord-player';

export const directMedia = definePlugin({
  id: 'example.direct-media',
  kind: 'source',
  setup(ctx) {
    ctx.on('search.query.match', ({ query }) =>
      /^https?:\/\/.*\.(mp3|ogg|wav)(\?.*)?$/i.test(query) ? { score: 100 } : null,
    );

    ctx.on('search.query.resolve', ({ query }) => ({
      playlist: null,
      tracks: [
        new Track({
          title: new URL(query).pathname.split('/').pop() || 'Audio',
          url: query,
        }),
      ],
    }));

    ctx.on('track.stream', ({ track }) => ({ url: track.url }));
  },
});
```

The Player in step 1 already registers this plugin with `plugins: [directMedia()]`. Don't create a second Player.

This example accepts direct audio file URLs, not website pages or search terms. **Do not allow untrusted users to submit arbitrary URLs to this example in production.** Validate allowed hosts and redirects and block private-network destinations first.

Once you're ready to add more providers, see [source plugins](/docs/plugins) and [legacy extractor compatibility](/docs/plugins/legacy-extractors).
