# Repository instructions

## Git commits

When committing changes to the repository, co-author the commit as the coding agent.

## API documentation

- Add clear JSDoc to every exported class, interface, type, property, and method in `packages/discord-player`.
- Document every public method parameter with an `@param` entry and describe return values when the behavior is not obvious.
- Keep the JSDoc aligned with actual Remedia capabilities and call out unsupported or deferred behavior.

## Code spacing

Give code breathing room: use blank lines between declarations, methods, test cases, and logical steps within functions. Keep closely related statements grouped, and keep documentation comments attached to the declarations they describe. Avoid dense blocks of code with no visual separation; preserve this spacing when formatting.
