# Security policy

Remedia is under development. Please do not report security vulnerabilities in public issues or
pull requests.

Use GitHub's private vulnerability reporting form from the repository's **Security** tab if it is
available. If private vulnerability reporting is not enabled, contact the repository owner or a
maintainer privately through GitHub. Include the affected revision, impact, reproduction steps, and
any relevant logs, with secrets removed.

Maintainers will acknowledge reports when possible, investigate them, and coordinate a fix and
disclosure with the reporter. Please allow time for a fix before sharing details publicly.
